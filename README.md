# 🛒 Americanas Clone - Front-end

Este é um projeto de estudo que replica a interface visual de uma loja de e-commerce inspirada no design da **Americanas**. O foco principal é a criação de um layout responsivo, limpo e funcional utilizando tecnologias web fundamentais.

## 🚀 Demonstração

Você pode visualizar o projeto online através do GitHub Pages:
[🔗 Clique aqui para acessar o site](https://seu-usuario.github.io/nome-do-seu-repositorio/)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído "do zero" (Vanilla) para consolidar conhecimentos em:

* **HTML5:** Estruturação semântica de dados.
* **CSS3:** Estilização moderna com Flexbox e Grid Layout.
* **JavaScript:** Lógica de interação (adicionar ao carrinho, manipulação de DOM).
* **GitHub Pages:** Hospedagem estática do projeto.

---

## 📦 Funcionalidades

- [x] **Header Fiel:** Barra de busca e menu de usuário com as cores da marca.
- [x] **Vitrine Dinâmica:** Grid de produtos responsivo que se ajusta a qualquer tela.
- [x] **Carrinho de Compras:** Sistema de contagem de itens em tempo real via JS.
- [x] **Hover Effects:** Feedback visual ao passar o mouse sobre os produtos.
